# mtDNA Analyzer — Windows downloads

[Download the latest Windows application](https://github.com/Ferdi1706/mtDNA-Analyzer-Downloads/releases/latest/download/mtDNA_Analyzer_Desktop.exe)

A device-bound license is required for analysis. Existing projects can be opened and saved in read-only mode without an active license. Project and sequence data are processed locally.

This repository distributes application binaries and signed update metadata. It contains no laboratory projects, genetic data, source repository, license keys or private signing keys. GitHub's automatically generated source archives contain this download repository's documentation, not the application source.

Updates are checked on request in **License & updates**. The application verifies the Ed25519 manifest signature and executable SHA-256 before installation. Save the active project before updating.

Release assets: `mtDNA_Analyzer_Desktop.exe`, `update.json`, `update.json.sig`.

Licensing is handled separately through Keygen. This update process does not create Keygen release objects.
